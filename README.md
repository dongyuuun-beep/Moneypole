# MoneyPole

예금·적금·입출금자유예금·CMA의 공식 공시를 비교하는 정적 웹입니다.

## 매일 업데이트

`.github/workflows/update.yml`이 기본 브랜치에서 매일 **한국 시간 02:17**에 실행됩니다. GitHub 예약 실행은 지연되거나 누락될 수 있으므로 화면은 예약 시각이 아닌 마지막 성공 시각을 표시합니다. PR만 만든 상태에서는 운영 사이트와 기본 브랜치의 예약 작업이 바뀌지 않습니다.

| 데이터 | 출처 | 지원 범위 |
|---|---|---|
| 예금·적금 | 금융감독원 금융상품한눈에 API | 은행·저축은행, 전체 페이지·기간 옵션 |
| 파킹통장 | 저축은행중앙회 입출금자유예금 공시 | 공시 목록 전체. 일반 입출금상품도 포함 |
| CMA | KB증권 공식 모바일 화면에서 사용하는 JSON | 개인 자동투자 RP형·발행어음형 |
| 시중은행 파킹통장 | 은행연합회 기존 URL | 오류 응답으로 지원 보류. 수집 성공으로 표시하지 않음 |

저축은행중앙회와 KB증권은 계약된 공개 API가 아닌 **공식 웹 화면의 데이터 요청**을 사용합니다. 주소·응답 형식 변경을 모니터링해야 합니다. [상세 설계 및 대안](docs/architecture.md)을 참고하세요.

### GitHub 설정

- 기존 Repository Secret `FSS_API_KEY`를 그대로 사용합니다. 키를 코드나 브라우저에 넣지 마세요.
- Actions가 활성화되어 있어야 합니다. 워크플로우는 `contents: write` 권한을 요청하며, 브랜치 보호·조직 정책이 직접 푸시를 막으면 별도 봇 PR 발행 방식으로 바꿔야 합니다.
- GitHub Pages가 `main`의 루트에서 배포되는 기존 설정을 유지합니다.
- `Actions → MoneyPole Daily Rate Update → Run workflow`에서 수동 갱신할 수 있습니다.
- `accept_large_changes`는 공식 원문에서 3%p 초과 변동을 확인한 경우에만 선택합니다.
- 실패한 실행은 Job summary와 `rate-update-report` 아티팩트를 확인합니다. GitHub의 개인 Actions 알림 설정으로 실패 알림을 받을 수 있습니다.
- 공개 저장소의 장기 미활동 등으로 예약 실행이 비활성화될 수 있습니다. `Actions` 탭과 상품 확인 시각을 확인하세요.

### 실패 시 동작

출처별로 전체 응답 검증을 통과한 데이터만 병합합니다. 한 출처가 실패해도 다른 출처는 갱신하며, 실패 출처의 금리·이력·마지막 성공 시각은 보존합니다. 실패·목록 누락·큰 금리 변동은 워크플로우 실패로 보고합니다. 상품이 응답에서 빠져도 판매 종료로 추정해 삭제하지 않으며, 공식 판매 여부를 검토한 뒤 기존 레코드를 정리해야 합니다. JSON 파일은 임시 파일을 작성한 뒤 교체합니다.

`update_status.json`에는 출처별 성공·실패와 수집 범위를 저장합니다. 상품 확인이 48시간 이상 지연되면 웹에서 지연 상태를 표시합니다. 금리 적용일, 공시일, 수집 확인일은 별도 필드입니다.

### 계산 범위

- 예금: 선택 기간의 단리 계산.
- 적금: 매월 같은 금액을 납입하는 단리 추정. FSS에서 자유적립식으로 확인된 옵션은 계산하지 않습니다.
- CMA: 선택 일수 기준 365일 단리 추정. 실제 재투자 효과는 미반영.
- 파킹통장: 공시된 최고금리·적용 금액·우대조건·구간 원문을 표시합니다. 공시 최저·최고 두 숫자만으로 구간별 이자를 추정하지 않습니다. 현재 수집 상품의 `rate_model`은 `unverified_tiers`이며 예상 이자를 제공하지 않습니다.
- 추후 `verified_tiers` 상품은 검증된 연속 금액 구간(`rate_tiers`)으로 계산할 수 있습니다. 잔액 전체 적용 방식은 별도 모델을 구현해야 하며 이 모델로 대체하지 마세요.
- 일반과세 세후 이자는 15.4%를 가정한 참고값입니다. 복리·비과세·개별 과세 및 실제 납입일 계산은 미지원입니다.

## 로컬 실행

```sh
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
node --test tests/rates.test.mjs
python -m http.server 8000
```

`http://localhost:8000`으로 접속합니다. 모듈을 사용하므로 HTML 파일을 직접 열지 마세요. `FSS_API_KEY`는 환경변수로 설정한 뒤 `.venv/bin/python update_rates.py`를 실행합니다. 키가 없으면 예금·적금은 그대로 보존하고 나머지 출처를 수집하며 종료 코드는 1입니다. 운영 파일을 건드리지 않고 실행하려면 기존 `data.json`을 별도 폴더에 복사한 뒤 `--output-dir /tmp/moneypole-check`를 사용하세요.
