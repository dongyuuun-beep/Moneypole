# MoneyPole

예금·적금·파킹통장·CMA의 공시 금리와 가입 조건을 비교합니다.

**[금리 비교](https://dongyuuun-beep.github.io/Moneypole/)** · **[지역 지원금](https://dongyuuun-beep.github.io/Moneypole/support.html)**

## 제공 정보

| 구분 | 공식 출처 | 수집 범위 |
|---|---|---|
| 예금·적금 | 금융감독원 금융상품한눈에 API | 은행·저축은행의 금리와 기간별 옵션 |
| 저축은행 파킹통장 | 저축은행중앙회 공시 | 입출금자유예금·우대조건·적용 한도 |
| 은행 파킹통장 | 카카오뱅크 공식 안내 | 세이프박스 기본금리·입금한도 |
| CMA | KB증권 공식 안내 | 개인 RP형·발행어음형 |
| 지역 지원금 | 서울·화성·용인·부산·부안 공식 홈페이지 | 등록된 게시판의 지원 공고·사업 안내 |

화성시는 주거·출산·입학·보험·생활 혜택과 경기도 공통 교통·기후보험 안내도 매일 확인합니다. 보험·할인과 지원금 접수를 구분하며, 소개 페이지 조회가 신청 가능·예산 잔액 확인을 뜻하지는 않습니다.

## 데이터 갱신

- GitHub Actions에서 매일 한국 시간 **금리 02:17 / 지역 지원금 02:47**에 공식 출처를 확인합니다. 지원금은 API 키 없이 HTML을 수집합니다.
- 공식 수집에서 누락되거나 수집에 실패한 상품, 확인 시각이 48시간을 넘은 상품은 비교·이자 계산에서 제외하고 이전 기록만 보존합니다. 공식 금리가 다시 확인되면 복귀합니다.
- 개별 상품 누락은 보고서에 남기며 실패 알림을 보내지 않습니다. 실제 수집 오류나 기존 상품의 20% 이상·5개 이상 대량 누락은 실패로 알립니다.
- 예약 실행이나 원천 공시가 지연될 수 있으므로, 매일 또는 1주일 이내 갱신을 보장하지는 않습니다. 확인 시각과 금리 적용일은 다릅니다.
- [실행 기록](https://github.com/dongyuuun-beep/Moneypole/actions/workflows/update.yml)에서 성공·실패를 확인하고 수동 실행할 수 있습니다. 예금·적금 수집은 기존 `FSS_API_KEY` Secret을 사용합니다.

## 이용 시 참고

예상 이자는 현재 금리를 기준으로 한 단리 추정치입니다. 금액 구간·이자 방식이 검증되지 않은 상품은 계산하지 않습니다. 가입 전 공식 안내의 우대조건·중도해지 조건·예금자보호 여부를 확인하세요.

지역 지원 공고는 수급 자격을 판정한 결과가 아닙니다. 마감·기간 확인 필요 상태를 구분하며, 이미지·첨부파일에만 있는 조건과 조기마감은 공식 원문에서 확인하세요.
